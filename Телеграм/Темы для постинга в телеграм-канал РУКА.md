# Темы для постинга в телеграм-канал РУКА

## Сырые темы

*Сюда попадают темы для постов, ещё не раскрытые в текст — просто идея, одной строкой.*

## Разобранные

*Сюда попадают темы, для которых уже готов текст поста, но пост ещё не опубликован.*

*Формат записи (для бота): `<!-- topic id=T-000N status=ready -->` на отдельной строке, дальше текст поста (можно в несколько строк), при наличии картинки — последней строкой `Картинка: путь/к/файлу`, и в конце `<!-- /topic -->` на отдельной строке. ID придумывается вручную по порядку (T-0001, T-0002…) при добавлении новой разобранной темы.*

## Опубликованные

*Сюда попадают уже опубликованные посты — с датой публикации. Записи отсюда не удаляются.*

*Формат записи — тот же блок, что и в «Разобранных», только `status=published` и добавляется `date=ДД.ММ.ГГГГ`; сюда блок переносит бот автоматически при публикации, вручную сюда ничего добавлять не нужно.*
