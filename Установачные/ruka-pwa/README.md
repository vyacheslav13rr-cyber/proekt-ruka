# РУКА — Менеджер (PWA)

Прототип, упакованный как веб-приложение (PWA). После публикации на любом
бесплатном хостинге его можно открыть в телефоне и «установить» — иконка
ляжет на рабочий стол и будет открываться как обычное приложение, без адресной строки.

## Состав папки

```
index.html              — сам прототип
manifest.webmanifest     — имя, иконка, цвет темы для установки
sw.js                     — офлайн-кэш (после первого открытия работает без сети)
icons/                    — иконки приложения всех нужных размеров
```

Ничего внутри `index.html` менять не нужно — все ссылки на манифест, иконки
и сервис-воркер уже прописаны как относительные пути. Важно: **при загрузке
на хостинг сохраняйте структуру папок как есть** — `manifest.webmanifest`,
`sw.js` и `icons/` должны лежать рядом с `index.html`, не внутри вложенной папки.

## Публикация — GitHub Pages (рекомендуется, ссылка постоянная и не протухает)

В репозитории уже есть готовая ветка **`gh-pages`** — в её корне лежат ровно
эти четыре пункта (`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`),
без кириллицы и пробелов в пути, плюс файл `.nojekyll` (чтобы GitHub не
пропускал файлы через Jekyll — на кириллических путях и больших HTML-файлах
это иногда даёт пустую белую страницу). Включить публикацию — разовая
настройка на 1 минуту:

1. На странице репозитория на github.com откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Ветка — **`gh-pages`**, папка — **`/ (root)`** → **Save**.
4. Через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<репозиторий>/` — эта ссылка постоянная.

Ветка `gh-pages` не синхронизируется с `main` автоматически — при обновлении
прототипа её нужно обновить тем же способом, каким обновляется эта папка
(`Установачные/ruka-pwa`), см. «Обновление прототипа» ниже.

## Публикация — Netlify (альтернатива, тоже бесплатно)

**С аккаунтом (ссылка постоянная):** зарегистрируйтесь на **netlify.com**,
в панели **Add new site → Deploy manually**, перетащите папку `ruka-pwa` —
сайт опубликуется на `https://ваш-сайт.netlify.app`.

**Без регистрации (Netlify Drop, app.netlify.com/drop):** быстрее всего, но
**ссылка временная** и рано или поздно перестаёт открываться — это самая
частая причина, почему установленное на телефон приложение вдруг «не
загружается» ни по вайфаю, ни по мобильной сети: ссылка просто протухла,
а не сломался сам прототип. Для постоянной ссылки — GitHub Pages выше или
Netlify с аккаунтом.

## Установка на телефон

**Android (Chrome):**
Откройте ссылку → в меню (три точки) выберите **«Установить приложение»**
или **«Добавить на главный экран»**. Иконка появится на рабочем столе.

**iPhone (Safari — обязательно Safari, не Chrome):**
Откройте ссылку → нажмите кнопку «Поделиться» (квадрат со стрелкой вверх)
→ **«На экран “Домой”»** → **«Добавить»**.

После установки приложение открывается отдельной иконкой, без строки браузера,
и один раз открыв его при интернете — дальше прототип работает и без сети.

## Обновление прототипа

Если позже пришлёте новую версию `index.html` — просто загрузите её заново
тем же способом (перетащить в Netlify / залить в ветку `gh-pages` на GitHub,
заменив файлы). Строку в `sw.js` (`CACHE = 'ruka-manager-v...'`) обязательно
менять на следующий номер при каждом обновлении — иначе телефон ещё
какое-то время может показывать старую версию из офлайн-кэша.
