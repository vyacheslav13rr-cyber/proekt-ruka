# РУКА — Менеджер (PWA)

Прототип, упакованный как веб-приложение (PWA). После публикации на любом
бесплатном хостинге его можно открыть в телефоне и «установить» — иконка
ляжет на рабочий стол и будет открываться как обычное приложение, без адресной строки.

## Состав папки

```
index.html              — сам прототип
manifest.webmanifest     — имя, иконка, цвет темы для установки
sw.js                     — офлайн-кэш (после первого открытия работает без сети)
icons/                    — иконки приложения всех нужных размеров
```

Ничего внутри `index.html` менять не нужно — все ссылки на манифест, иконки
и сервис-воркер уже прописаны как относительные пути. Важно: **при загрузке
на хостинг сохраняйте структуру папок как есть** — `manifest.webmanifest`,
`sw.js` и `icons/` должны лежать рядом с `index.html`, не внутри вложенной папки.

## Публикация — Netlify Drop (самый простой способ, без регистрации)

1. Откройте **app.netlify.com/drop** в браузере на компьютере.
2. Перетащите на страницу всю папку `ruka-pwa` целиком.
3. Через несколько секунд Netlify выдаст ссылку вида
   `https://случайное-имя.netlify.app` — сайт уже опубликован.
4. Откройте эту ссылку на телефоне (можно отправить себе в мессенджер).

Ограничение способа: без регистрации ссылка и сайт живут ограниченное время
(обычно можно зайти и подтвердить/закрепить через бесплатный аккаунт Netlify,
если нужно, чтобы ссылка не пропадала).

## Публикация — Netlify с аккаунтом (ссылка постоянная, тоже бесплатно)

1. Зарегистрируйтесь на **netlify.com** (можно через Google-аккаунт).
2. В панели нажмите **Add new site → Deploy manually**.
3. Перетащите папку `ruka-pwa` — сайт опубликуется на постоянном адресе
   `https://ваш-сайт.netlify.app`, его можно переименовать в настройках сайта.

## Публикация — GitHub Pages (тоже бесплатно и без ограничения по времени)

1. Создайте аккаунт на **github.com**, если его нет.
2. Создайте новый репозиторий (кнопка **New**), например `ruka-manager`.
3. На странице репозитория **Add file → Upload files** — загрузите всё
   содержимое папки `ruka-pwa` (включая подпапку `icons`).
4. Зайдите в **Settings → Pages**, в разделе Source выберите ветку `main`
   и нажмите **Save**.
5. Через минуту сайт будет доступен по адресу
   `https://ваш-логин.github.io/ruka-manager/`.

## Установка на телефон

**Android (Chrome):**
Откройте ссылку → в меню (три точки) выберите **«Установить приложение»**
или **«Добавить на главный экран»**. Иконка появится на рабочем столе.

**iPhone (Safari — обязательно Safari, не Chrome):**
Откройте ссылку → нажмите кнопку «Поделиться» (квадрат со стрелкой вверх)
→ **«На экран “Домой”»** → **«Добавить»**.

После установки приложение открывается отдельной иконкой, без строки браузера,
и один раз открыв его при интернете — дальше прототип работает и без сети.

## Обновление прототипа

Если позже пришлёте новую версию `index.html` — просто загрузите её заново
тем же способом (перетащить в Netlify / загрузить в GitHub, заменив файл).
Иконку в `sw.js` (`CACHE = 'ruka-manager-v1'`) стоит поменять на `v2`, `v3`
и т.д. при каждом обновлении — иначе телефон может показывать старую
сохранённую версию из офлайн-кэша ещё какое-то время.
